# Сайты и портфолио

Проект с сайтами и портфолио. Отдельный от агента: это не агент, и
в его репозитории ему не место.

* Адрес: `https://zagent.do.am/`
* Каталог: `https://zagent.do.am/catalog.html`

## Что внутри

| Папка | Что это |
|---|---|
| `site/` | исходники: 52 страницы, макеты, портфолио, справочники |
| `portfolios/` | портфолио отдельных авторов |
| `tools/` | инструменты проекта: сборка, заливка, каталог, снимки |
| `site/demo/` | куда класть новые демки, баннеры и фоны |
| `site-dist/` | собранная версия, едет на хостинг (в git не входит) |

## Три команды

Сборка — из исходников в `site-dist`:

```powershell
python tools\build_site.py
```

Порядок важен: сначала сборка, потом `ai.json`, потом заливка.
Сборка очищает `site-dist`, и если прогнать `place_ai_config.py`
до неё, файлы пропадут и заливка прервётся с ошибкой про `ai.json`.

Заливка на хостинг:

```powershell
$env:ZAGENT_FTP_HOST='...'
$env:ZAGENT_FTP_USER='...'
$env:ZAGENT_FTP_PASS='...'
python tools\place_ai_config.py
python tools\upload_site.py
```

Проверка, что всё живо:

```powershell
python tools\check_host.py
```

Проверка настоящая, а не «просто код 200»: она ищет в теле страницы
заглушку хостинга и отсеивает слишком короткие ответы. Без этого
страница, отдающая 200 с чужим текстом, прошла бы незамеченной.

## Каталог

52 карточки, у 41 — настоящий снимок первого экрана.

Снимки снимаются отдельно, с живого сайта:

```powershell
python tools\make_shots.py
```

Портофолио выкладывает отдельный загрузчик, и их не было в списке
адресов для съёмки — из-за этого семь карточек показывали полосу из
палитры вместо снимка. Список дополнен.

## Новые демки

Класть в `site/demo/`, подробности в `site/demo/ЧТО-ЗДЕСЯ.md`.
Картинки — в `site/demo/_assets/`.

Демки, которые уже стали страницами, лежат в `site/demo/_готовое/`.
Они перенесены, а не удалены: готовая страница переписана при
выкладке, и исходник отличается от того, что лежит на хостинге.

Проверить, не стал ли какой демка страницей:

```powershell
python tools\find_demo_duplicates.py
```

## Границы публикации

Проверяются перед выкладкой, материалы не отвечающие — не
выкладываются:

* никаких внешних загрузок: CDN и чужие ссылки запрещены, всё
  скачивается локально;
* никаких чужих фотографий реальных людей и никаких дипфейков;
* никаких фото с несовершеннолетними и фрагментов тела;
* никаких чужих игр (GTA VI, Cyberpunk, Elsword);
* никакого платного стока (pngtree);
* никаких выдуманных клиентов, отзывов и цифр — на витрине без
  своего содержимого обязана стоять пометка, что это демонстрация.

## Известные особенности хостинга

* файл без расширения отдаётся с кодом 553 — расширения проставляет
  `tools/fix_extensions.py`;
* кэш браузера держится 20 дней, поэтому сборка ставит метки `?v=`;
* прокси хостинга обрывает соединение, которое долго молчит, — это
  касается ботов, не сайтов.

## Чего здесь нет и почему

* `site-dist/` — собранная копия, воспроизводится одной командой;
* `site/demo/_assets/` — временные картинки на 120 МБ, черновик;
* `publish/` — готовые архивы, собираются по требованию.

Ничего из этого в репозиторий не попадает: история помнит всё, а
каждая пересборка увеличивала бы его навсегда.
